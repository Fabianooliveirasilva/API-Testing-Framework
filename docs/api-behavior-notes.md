# Restful Booker API Behavior Notes

These observations were captured from a real smoke execution on **2026-11-01** against
`https://restful-booker.herokuapp.com`, using **@playwright/test 1.64.1**. The execution created
booking `1419`; additional IDs returned by permissive invalid payloads were also tracked and
deleted. Authentication tokens and credentials are intentionally redacted.

`documented` means the endpoint or scenario is described by the Restful Booker API documentation.
`not documented` means the observed behavior is recorded for compatibility knowledge only.

The smoke test used only resources created during the run. Every booking ID returned by a POST,
including IDs returned for permissive invalid payloads, was collected and deleted in the cleanup
phase using the valid token. These observations are evidence from one execution, not immutable
service guarantees; future tests should continue to report unexpected changes.
